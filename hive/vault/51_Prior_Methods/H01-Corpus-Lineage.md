# Prior HIVE corpus and evidence lineage

## Status

**Recovered evidence and proposals; no new HIVE training run in this audit.**

- The recovered collection contains **19 original files**: architecture plans, literature catalogs, software inventory, experiment bundle, figures, and application handoffs.
- The November 18 foundation says the integrated HIVE system was not built. A separate November 18 experiment report subsequently records small CPU mechanism studies. These statements describe different scopes; preserve both.
- November 19 documents specify v0.1 training and the SOL/Grok/Nemotron foundation workflow. A specification is not a completed implementation.

## What to preserve

- Original bytes and names in the archive; corrections belong on linked notes.
- Separate source, claim, experiment, decision, and implementation pages.
- All competing arms and negative outcomes.
- Original run environment: CPU/NumPy, no GPU and no downloaded model weights.

**Next path:** reproduce the archived studies locally, then attach new run IDs before comparing them with real-model HIVE experiments.
