# Video, studio interaction, and horror testbeds

## Earlier plans to carry forward

| Testbed | Recovered basis | Useful HIVE measurement |
|---|---|---|
| Video production/posting | Continuous upload coder prompt; media tools inventory | Verified completion, queue recovery, duplicate prevention, intervention burden |
| Live calls / MOM studio | MOM Channel Surf and voice/broadcast inventory | Response gaps, interruptions, scheduling, stream interference |
| Horror/haunt | AR mapping handoff and multi-agent orchestration plan | Spatial state validity, tracking confidence, reproducible encounter behavior |

## Evidence boundary

These are application plans and inventory observations. The recovered HIVE experiment archive does not contain benchmarks of autonomous uploading, natural live calls, or an integrated haunt director. MOM Channel Surf was observed running; that does not establish a working HIVE call loop.

The AR handoff already separates reconstruction, metric alignment, collision/occlusion assets, live tracking, and gameplay. Preserve those interfaces instead of treating a visual reconstruction as a complete world model.

## New path

Create replayable traces and reversible local tasks for each arena. Use the same event, evidence, budget, and promotion contracts. Keep production side effects governed by existing project authorization. Introduce learning in candidate workers and compare against the unchanged application baseline.

Link each new experiment to the original application handoff, the responsible HIVE capability, and the exact observed failure it aims to improve.
