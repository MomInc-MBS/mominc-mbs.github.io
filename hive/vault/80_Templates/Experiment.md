# Experiment template

## Required fields

Hypothesis; implementation fidelity; arms; independent variables; controls; data split; external-feedback access; total and active resource budgets; pilot; confirmatory design; metrics; falsifier; acceptance; raw artifact list.

## Completion rule

Use exact identifiers and measured values. Mark unavailable information explicitly. A proposed run has no fabricated timestamp, score, or completion status.

## Links to add

Parent topic; relevant prior method; supporting source; alternative or disputed path; experiment or decision; next research avenue.
