# CAMEL (Communicative Agents for Mind Exploration)

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Multi-agent framework  
**Original catalog label:** Succeeded — a prior classification, not this plan's experimental verdict.

## Prior description

An open-source Python multi-agent framework from KAUST that lets LLM agents autonomously cooperate via role-playing with inception prompting.

## Research lead carried forward

Copy CAMEL's role-playing inception prompting — explicit user/assistant roles with task-consistent instructions — and its scalable agent-society abstractions, but avoid its research-first sprawl by keeping HIVE's orchestration production-hardened and narrowly scoped.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
