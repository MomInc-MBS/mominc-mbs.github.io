# AgentVerse

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Multi-agent framework  
**Original catalog label:** Stalled/Abandoned — a prior classification, not this plan's experimental verdict.

## Prior description

AgentVerse is an open-source multi-agent framework that dynamically recruits LLM expert agents and loops through collaborative decision-making, action execution, and evaluation to solve tasks or run simulations.

## Research lead carried forward

Copy its dynamic expert-recruitment plus evaluation/feedback loop, but avoid flat free-form multi-agent discussion as the core — use bounded hierarchical orchestration with explicit evaluation gates and cost caps instead.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
