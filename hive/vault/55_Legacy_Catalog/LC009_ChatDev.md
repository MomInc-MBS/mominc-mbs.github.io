# ChatDev

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Multi-agent framework  
**Original catalog label:** In Progress — a prior classification, not this plan's experimental verdict.

## Prior description

An open-source multi-agent framework from OpenBMB/Tsinghua that originally simulated a virtual software company (CEO, CTO, programmer, tester) collaborating through chat chains, now pivoted to ChatDev 2.0 (DevAll), a zero-code YAML/visual multi-agent orchestration platform.

## Research lead carried forward

Copy its instructor/assistant chat-chain and communicative dehallucination for role-specialised agents, but avoid its rigid waterfall/company role-play — make orchestration a configurable workflow graph with human-in-the-loop, as ChatDev itself had to pivot to in 2.0.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
