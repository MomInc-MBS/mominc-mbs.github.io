# IBM TrueNorth / NorthPole

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Bio-inspired/Neuromorphic/Swarm  
**Original catalog label:** In Progress — a prior classification, not this plan's experimental verdict.

## Prior description

IBM's brain-inspired chip lineage: TrueNorth (2014) was a spiking neuromorphic chip with 1M neurons, superseded by NorthPole (2023), a synchronous digital neural-inference chip that co-locates memory and compute on-die to eliminate off-chip memory access.

## Research lead carried forward

Copy NorthPole's near-memory, low-precision spatial inference for low-latency, low-batch edge inference; avoid TrueNorth's spiking, incompatible programming model and vendor lock-in that blocked commercial adoption.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
