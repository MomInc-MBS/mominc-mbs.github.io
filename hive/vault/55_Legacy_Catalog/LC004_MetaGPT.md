# MetaGPT

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Multi-agent framework  
**Original catalog label:** Stalled/Abandoned — a prior classification, not this plan's experimental verdict.

## Prior description

An open-source Python multi-agent framework from DeepWisdom/FoundationAgents that simulates a software company — Product Manager, Architect, Project Manager, Engineer and QA agents collaborating via codified SOPs — to turn a one-line requirement into documents and code.

## Research lead carried forward

Copy MetaGPT's SOP-driven role handoffs and structured artifacts (PRD/design/tasks/code), but avoid rigid fixed software-company roles and a demo-first framework with no maintenance owner — keep roles flexible, verifiable, and actively maintained.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
