# NARS (Non-Axiomatic Reasoning System)

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Cognitive architecture/AGI  
**Original catalog label:** In Progress — a prior classification, not this plan's experimental verdict.

## Prior description

A general-purpose AGI cognitive architecture by Pei Wang that reasons with Non-Axiomatic Logic (NAL) in the language Narsese, learning and acting under insufficient knowledge and resources.

## Research lead carried forward

Copy its AIKR principle and experience-grounded truth values (frequency + confidence) for resource-bounded, revisable reasoning under uncertainty, but avoid betting HIVE's core on a symbolic-only system with no LLM-scale adoption or commercial traction.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
