# Intel Loihi 2

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Bio-inspired/Neuromorphic/Swarm  
**Original catalog label:** In Progress — a prior classification, not this plan's experimental verdict.

## Prior description

Intel Loihi 2 is a second-generation digital neuromorphic research chip that runs asynchronous spiking neural networks with on-chip learning for ultra-low-power, event-driven edge workloads.

## Research lead carried forward

Copy Loihi 2's event-driven, sparse, on-chip-learning design for ultra-low-power edge agents, but avoid its bespoke programming model — build on standard AI frameworks or the ecosystem dies with the SDK.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
