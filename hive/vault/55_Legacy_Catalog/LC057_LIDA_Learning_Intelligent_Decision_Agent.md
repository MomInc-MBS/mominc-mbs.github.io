# LIDA (Learning Intelligent Decision Agent)

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Cognitive architecture/AGI  
**Original catalog label:** Stalled/Abandoned — a prior classification, not this plan's experimental verdict.

## Prior description

LIDA is a University of Memphis cognitive architecture by Stan Franklin and colleagues that implements Bernard Baars' Global Workspace Theory as repeating ~10 Hz cognitive cycles of perception, competitive attention/broadcast, and action selection with learning across multiple memory systems.

## Research lead carried forward

Copy LIDA's competitive attention-codelet broadcast and three-phase cognitive cycle (understand, attend/broadcast, act/learn), but avoid its hand-coded codelets, monolithic Java framework, and restrictive non-commercial licence.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
