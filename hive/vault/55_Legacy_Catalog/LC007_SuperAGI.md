# SuperAGI

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Multi-agent framework  
**Original catalog label:** Succeeded — a prior classification, not this plan's experimental verdict.

## Prior description

A dev-first open-source autonomous AI agent framework (Python/FastAPI + GUI, tool marketplace, memory, workflows) whose company pivoted to a commercial AI sales/GTM platform and was acquired by QuestionPro in November 2026.

## Research lead carried forward

Copy the pivot discipline — monetize a narrow, verifiable business workflow (sales/GTM agents) rather than the open framework — but avoid letting the open-source core rot: unpatched security flaws and a stalled repo destroyed developer trust even as the company itself exited successfully.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
