# Voyager

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Memory/Verification/Self-improvement  
**Original catalog label:** Stalled/Abandoned — a prior classification, not this plan's experimental verdict.

## Prior description

Voyager is the first LLM-powered embodied lifelong-learning agent in Minecraft that autonomously explores, writes and self-verifies executable JavaScript skills via GPT-4, and stores them in a growing reusable skill library without fine-tuning.

## Research lead carried forward

Copy Voyager's executable skill library plus self-verification/critic loop so capabilities compound, but avoid building on its frozen, single-environment research codebase with expensive black-box GPT-4 calls and no maintained runtime.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
