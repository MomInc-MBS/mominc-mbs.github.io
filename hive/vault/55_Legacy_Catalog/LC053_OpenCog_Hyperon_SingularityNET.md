# OpenCog Hyperon / SingularityNET

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Cognitive architecture/AGI  
**Original catalog label:** In Progress — a prior classification, not this plan's experimental verdict.

## Prior description

OpenCog Hyperon is SingularityNET's open-source neural-symbolic cognitive architecture for AGI, built around the AtomSpace knowledge metagraph and the MeTTa programming language, with SingularityNET as its decentralized AI marketplace and funding/coordination layer.

## Research lead carried forward

Copy the neural-symbolic AtomSpace + MeTTa idea of a shared, inspectable knowledge metagraph for reasoning and memory, but avoid Hyperon's trap of building a bespoke language and three parallel, non-integrated stacks before proving one working end-to-end agent loop.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
