# DARPA SyNAPSE (Systems of Neuromorphic Adaptive Plastic Scalable Electronics)

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Bio-inspired/Neuromorphic/Swarm  
**Original catalog label:** Failed — a prior classification, not this plan's experimental verdict.

## Prior description

A DARPA programme (2008-c.2016) to build brain-inspired, low-power neuromorphic computers scaling toward biological levels, whose flagship output was IBM's TrueNorth neurosynaptic chip.

## Research lead carried forward

HIVE should copy SyNAPSE's vertically integrated ecosystem (chip/simulator/language/applications) but avoid betting on exotic hardware or a new programming paradigm without a mainstream software on-ramp and a commercial customer from day one.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
