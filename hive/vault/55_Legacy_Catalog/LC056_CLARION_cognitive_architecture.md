# CLARION cognitive architecture

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Cognitive architecture/AGI  
**Original catalog label:** In Progress — a prior classification, not this plan's experimental verdict.

## Prior description

CLARION (Connectionist Learning with Adaptive Rule Induction On-line) is Ron Sun's hybrid cognitive architecture in which every subsystem — action-centered, non-action-centered, motivational, and metacognitive — has an explicit symbolic top level and an implicit connectionist bottom level that interact via bottom-up and top-down learning.

## Research lead carried forward

Copy CLARION's dual explicit/implicit representation, bottom-up rule extraction, and metacognitive monitoring as design principles, but avoid adopting it as a whole platform — use LLMs for the implicit layer and explicit rules/gates for the top layer instead.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
