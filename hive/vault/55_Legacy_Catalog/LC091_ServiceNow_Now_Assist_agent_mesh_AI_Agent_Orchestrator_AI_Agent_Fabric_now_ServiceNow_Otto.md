# ServiceNow Now Assist / agent mesh (AI Agent Orchestrator + AI Agent Fabric, now ServiceNow Otto)

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Orchestration/Enterprise  
**Original catalog label:** In Progress — a prior classification, not this plan's experimental verdict.

## Prior description

ServiceNow's generative-AI layer on the Now Platform — Now Assist skills plus multi-agent AI Agents coordinated by AI Agent Orchestrator and connected to external agents via AI Agent Fabric (MCP/A2A) — now unified under the ServiceNow Otto experience.

## Research lead carried forward

Copy the pattern of grounding agents in a shared system of record and a central orchestrator with a governance control tower, and price/meter agent runs by outcome cost — but avoid bundling agents behind premium tiers and opaque consumption metering that slows adoption.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
