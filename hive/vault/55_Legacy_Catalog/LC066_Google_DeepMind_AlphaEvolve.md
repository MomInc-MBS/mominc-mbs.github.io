# Google DeepMind AlphaEvolve

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Memory/Verification/Self-improvement  
**Original catalog label:** Succeeded — a prior classification, not this plan's experimental verdict.

## Prior description

Google DeepMind's evolutionary coding agent that pairs Gemini Flash/Pro models with automated evaluators to iteratively discover and optimize algorithms expressed as code.

## Research lead carried forward

Copy the evaluator-first evolutionary loop: let LLMs propose freely but let fast, automatic, verifiable scoring select and mutate winners — and avoid AlphaEvolve's closed, evaluator-dependent design, which only works where a trustworthy automatic score exists.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
