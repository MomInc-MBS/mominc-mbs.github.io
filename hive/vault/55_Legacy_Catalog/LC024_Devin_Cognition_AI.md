# Devin (Cognition AI)

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Orchestration/Enterprise  
**Original catalog label:** Succeeded — a prior classification, not this plan's experimental verdict.

## Prior description

An autonomous AI software engineer from Cognition that takes a ticket, plans, codes, tests and debugs in its own cloud sandbox, and returns a pull request.

## Research lead carried forward

Copy Devin's delegation-plus-verification pattern — scoped tasks, sandboxed execution, tests/CI as the acceptance gate, and human-reviewed PRs — and avoid launching on a hyped demo before the verification loop and pricing make real adoption possible.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
