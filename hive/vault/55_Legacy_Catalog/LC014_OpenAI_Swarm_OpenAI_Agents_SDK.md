# OpenAI Swarm / OpenAI Agents SDK

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Multi-agent framework  
**Original catalog label:** In Progress — a prior classification, not this plan's experimental verdict.

## Prior description

OpenAI's lightweight open-source multi-agent orchestration framework built on Agents, handoffs, guardrails and tracing, originally released as the experimental Swarm and productionised as the Agents SDK.

## Research lead carried forward

Copy Swarm's thin Agents-plus-handoffs primitives with built-in tracing and guardrails, and avoid maintaining a separate experimental fork once a production SDK exists.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
