# Google A2A Protocol (Agent2Agent) + ADK ecosystem

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Multi-agent framework  
**Original catalog label:** In Progress — a prior classification, not this plan's experimental verdict.

## Prior description

Google's open, vendor-neutral Agent2Agent (A2A) protocol for agents built on different frameworks to discover each other and delegate tasks, plus the Agent Development Kit (ADK), Google's open-source multi-agent SDK in Python, TypeScript, Go, Java and Kotlin.

## Research lead carried forward

Copy the A2A/MCP dual stack — MCP for tools, A2A Agent Cards for cross-agent discovery and delegation — and neutral, open governance; avoid proprietary inter-agent glue that locks HIVE agents to one framework.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
