# ACT-R (Adaptive Control of Thought—Rational)

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Cognitive architecture/AGI  
**Original catalog label:** Succeeded — a prior classification, not this plan's experimental verdict.

## Prior description

A symbolic cognitive architecture from Carnegie Mellon that models human cognition as interacting modules (declarative and procedural memory, perception, motor) coordinated through buffers and production rules, implemented as a Common Lisp interpreter.

## Research lead carried forward

Copy ACT-R's activation-based declarative memory (time decay plus frequency-of-use boosts) and its strict buffer-mediated module separation for memory retrieval and auditability; avoid its Lisp-only core and monolithic interpreter — build the same ideas as Python-native, LLM-compatible modules.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
