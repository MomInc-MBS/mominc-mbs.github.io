# Google AutoML / Neural Architecture Search

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Orchestration/Enterprise  
**Original catalog label:** Succeeded — a prior classification, not this plan's experimental verdict.

## Prior description

Google's AutoML is a cloud suite that uses Neural Architecture Search (NAS) and transfer learning to automatically discover model architectures and hyperparameters for custom vision, tabular, text, and video models, now delivered inside Vertex AI.

## Research lead carried forward

Copy bounded, cost-capped automated search with verified benchmarks, but avoid open-ended architecture search without a budget and a human-verifiable winner — HIVE should search configurations, not reinvent models from scratch.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
