# IBM BeeAI / watsonx Orchestrate

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Orchestration/Enterprise  
**Original catalog label:** In Progress — a prior classification, not this plan's experimental verdict.

## Prior description

IBM's paired agentic stack: BeeAI is the open-source Python/TypeScript framework for building production multi-agent systems, and watsonx Orchestrate is IBM's commercial enterprise platform for building, orchestrating, governing, and observing those agents at scale.

## Research lead carried forward

Copy the open-protocol interop (A2A/MCP) plus a governance/observability control plane over heterogeneous agents, but avoid betting HIVE on a single vendor's 0.x framework — abstract agents behind standard protocols and pin versions.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
