# SynSense Speck

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Bio-inspired/Neuromorphic/Swarm  
**Original catalog label:** Succeeded — a prior classification, not this plan's experimental verdict.

## Prior description

SynSense Speck is an event-driven neuromorphic vision SoC integrating a 128x128 dynamic vision sensor with a ~330,000-neuron spiking CNN processor for sub-milliwatt, always-on edge vision.

## Research lead carried forward

Copy Speck's sensor-plus-compute co-design and event-driven sparsity for always-on, milliwatt perception; avoid its narrow 128x128, inference-only, vendor-locked toolchain that limits general workloads.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
