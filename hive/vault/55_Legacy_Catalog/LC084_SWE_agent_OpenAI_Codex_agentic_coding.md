# SWE-agent / OpenAI Codex agentic coding

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Specialist/Adapter  
**Original catalog label:** Succeeded — a prior classification, not this plan's experimental verdict.

## Prior description

An agentic coding system — SWE-agent as the Princeton academic agent that autonomously fixes GitHub issues via a purpose-built agent-computer interface, and OpenAI Codex as its commercial successor: a sandboxed CLI/cloud/IDE agent that writes, tests and proposes code changes in real repositories.

## Research lead carried forward

Copy the narrow verifiable loop — purpose-built tools, sandboxed execution, and test-based pass/fail verification — and keep scaffolding minimal around the strongest model rather than building a heavy multi-agent framework first.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
