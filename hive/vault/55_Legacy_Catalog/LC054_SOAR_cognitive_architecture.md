# SOAR cognitive architecture

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Cognitive architecture/AGI  
**Original catalog label:** In Progress — a prior classification, not this plan's experimental verdict.

## Prior description

A symbolic cognitive architecture for general intelligent agents, built around a repeating decision cycle that selects and applies operators using working, procedural, semantic and episodic memory, with chunking and reinforcement learning.

## Research lead carried forward

Copy Soar's unified decision cycle with separate procedural, semantic and episodic memory plus impasse-driven chunking/learning, but avoid hand-authored production rules as the sole knowledge-entry path — use LLM translation into rules, as in NL2GenSym.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
