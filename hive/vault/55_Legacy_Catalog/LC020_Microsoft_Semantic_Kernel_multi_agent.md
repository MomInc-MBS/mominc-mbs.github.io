# Microsoft Semantic Kernel multi-agent

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Multi-agent framework  
**Original catalog label:** Succeeded — a prior classification, not this plan's experimental verdict.

## Prior description

Microsoft's open-source, MIT-licensed SDK for building AI agents and multi-agent systems with plugins, connectors, memory, and orchestration patterns in .NET, Python, and Java.

## Research lead carried forward

Copy Semantic Kernel's enterprise plumbing and ready-made orchestration patterns (sequential, concurrent, group chat, handoff) plus MCP/A2A interop, and avoid maintaining two overlapping frameworks or forcing developers to hand-roll agent turn-taking and termination.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
