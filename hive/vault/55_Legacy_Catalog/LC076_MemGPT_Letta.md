# MemGPT / Letta

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Memory/Verification/Self-improvement  
**Original catalog label:** In Progress — a prior classification, not this plan's experimental verdict.

## Prior description

An open-source platform (Apache 2.0) for stateful AI agents whose LLM manages its own tiered, persistent memory, now shipped as the Letta Code agent harness with git-backed MemFS memory.

## Research lead carried forward

Copy versioned, self-editing persistent memory (git-backed MemFS) as a durable agent state layer, but avoid tying memory to a single whole harness or breaking API compatibility in a pivot.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
