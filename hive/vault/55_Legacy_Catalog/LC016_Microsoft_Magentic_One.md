# Microsoft Magentic-One

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Multi-agent framework  
**Original catalog label:** Succeeded — a prior classification, not this plan's experimental verdict.

## Prior description

Microsoft Research's open-source generalist multi-agent system in which a lead Orchestrator plans, tracks progress in ledgers and replans while directing specialist WebSurfer, FileSurfer, Coder and ComputerTerminal agents to complete complex multi-step web and file-based tasks.

## Research lead carried forward

Copy the Orchestrator plus Task/Progress ledgers, stall detection and replanning with hard round/stall caps and human-in-the-loop plan review, and avoid unbounded autonomous web/file actions without Docker sandboxing and oversight.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
