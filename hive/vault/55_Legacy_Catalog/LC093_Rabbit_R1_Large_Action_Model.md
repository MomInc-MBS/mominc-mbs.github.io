# Rabbit R1 / Large Action Model

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Cognitive architecture/AGI  
**Original catalog label:** In Progress — a prior classification, not this plan's experimental verdict.

## Prior description

Rabbit R1 is a $199 handheld AI device running rabbitOS (based on Android) built around Rabbit's Large Action Model (LAM), pitched as an AI that operates apps and websites on the user's behalf instead of just answering questions.

## Research lead carried forward

Copy Rabbit's teach-mode idea of learning actions from demonstrated workflows, but avoid demo-first dedicated hardware and general-agent claims — ship the agent as software on devices users already own and prove reliability on narrow tasks first.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
