# Flower (Flower Labs)

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Orchestration/Enterprise  
**Original catalog label:** In Progress — a prior classification, not this plan's experimental verdict.

## Prior description

Flower (flwr) is an open-source, framework-agnostic Python framework for federated and collaborative AI, letting organizations train and run models on data that stays distributed across devices and organizational silos.

## Research lead carried forward

Copy Flower's framework-agnostic, federated orchestration model — a central SuperLink coordinating distributed SuperNode agents with compute moving to the data — and its Apache-2.0 open core plus paid enterprise platform monetization; avoid relying on a single central data pool when privacy or distributed ownership matters.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
