# Microsoft AutoGen

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Multi-agent framework  
**Original catalog label:** Failed — a prior classification, not this plan's experimental verdict.

## Prior description

Microsoft Research's open-source framework for building multi-agent AI applications in which LLM agents collaborate through structured conversation.

## Research lead carried forward

Copy AutoGen's conversation/group-chat orchestration and layered Core/AgentChat/Extensions separation, but avoid a breaking rewrite, single-vendor consolidation risk, and dependence on a framework without a stable API and migration path.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
