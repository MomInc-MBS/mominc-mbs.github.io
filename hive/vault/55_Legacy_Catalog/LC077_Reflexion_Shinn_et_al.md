# Reflexion (Shinn et al.)

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Memory/Verification/Self-improvement  
**Original catalog label:** Succeeded — a prior classification, not this plan's experimental verdict.

## Prior description

A framework in which a language agent improves across trials without weight updates by verbally reflecting on task feedback and storing those reflections in an episodic memory buffer that conditions its next attempt.

## Research lead carried forward

Copy the Actor-Evaluator-Self-Reflection loop with a small episodic memory of verbal lessons and bounded retries, but only where HIVE has a reliable external verifier — avoid unbounded self-critique on unverifiable tasks.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
