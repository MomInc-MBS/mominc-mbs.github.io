# OpenAgents (XLang Lab; listed in task as Tsinghua / OpenBMB)

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Multi-agent framework  
**Original catalog label:** Stalled/Abandoned — a prior classification, not this plan's experimental verdict.

## Prior description

An open-source platform for using and hosting language agents in everyday life, with three demo agents: a Data Agent, a Plugins Agent with 200+ tools, and a Web Agent for autonomous browsing.

## Research lead carried forward

Copy its application-level lesson — ship usable Data/Plugins/Web agents behind a simple chat UI for non-experts — but avoid treating an academic demo as a platform: HIVE needs named ownership, releases, patching, and durable multi-agent coordination from day one.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
