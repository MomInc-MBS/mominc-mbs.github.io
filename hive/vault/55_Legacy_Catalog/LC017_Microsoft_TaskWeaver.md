# Microsoft TaskWeaver

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Multi-agent framework  
**Original catalog label:** Failed — a prior classification, not this plan's experimental verdict.

## Prior description

Microsoft Research's open-source code-first agent framework that plans data-analytics tasks and executes LLM-generated Python in a stateful Jupyter kernel with plugins.

## Research lead carried forward

Copy its code-first, stateful execution model that preserves both chat and code/data history, but avoid building on a single-vendor research framework that can be archived when the vendor consolidates around a successor.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
