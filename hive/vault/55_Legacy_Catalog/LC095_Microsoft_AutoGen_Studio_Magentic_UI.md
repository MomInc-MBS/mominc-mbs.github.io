# Microsoft AutoGen Studio / Magentic-UI

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Multi-agent framework  
**Original catalog label:** Failed — a prior classification, not this plan's experimental verdict.

## Prior description

Microsoft's open-source multi-agent framework with a no-code Studio for building agent teams, and its human-centred web-agent prototype Magentic-UI (later MagenticLite) built on AutoGen/Magentic-One.

## Research lead carried forward

Copy Magentic-UI's human-in-the-loop co-planning, action guards, co-tasking and plan learning, but avoid building HIVE on a vendor research prototype or a single framework that can be archived and superseded.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
