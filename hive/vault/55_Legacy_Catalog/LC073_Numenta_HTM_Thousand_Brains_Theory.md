# Numenta HTM / Thousand Brains Theory

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Bio-inspired/Neuromorphic/Swarm  
**Original catalog label:** In Progress — a prior classification, not this plan's experimental verdict.

## Prior description

A neuroscience-first AI research program from Numenta, now the Thousand Brains Project nonprofit, building Monty — an open-source sensorimotor learning system in which many cortical-column-like modules build reference-frame models of objects through movement and vote to reach consensus.

## Research lead carried forward

Copy its modular, reference-frame-based voting/consensus idea for specialist modules, but avoid betting HIVE's core on this still-unproven, research-stage paradigm.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
