# Cyc / Cycorp

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Cognitive architecture/AGI  
**Original catalog label:** Stalled/Abandoned — a prior classification, not this plan's experimental verdict.

## Prior description

Cyc is a hand-built, logic-based commonsense ontology and reasoning engine developed by Cycorp to let AI reason like a human.

## Research lead carried forward

Copy Cyc's auditable, context-scoped symbolic reasoning and microtheories as a verification layer, but avoid hand-encoding broad commonsense — pair a small verified core with learned models instead.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
