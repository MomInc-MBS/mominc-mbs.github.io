# Ray / Anyscale

**Status:** historical import; current project condition and numerical claims are not reverified here.  
**Original catalog category:** Orchestration/Enterprise  
**Original catalog label:** Succeeded — a prior classification, not this plan's experimental verdict.

## Prior description

Ray is the open-source Python framework for distributed AI compute (training, data, serving, RL), and Anyscale is its managed commercial platform founded by Ray's Berkeley creators.

## Research lead carried forward

Copy Ray's winning formula — one simple Python API over distributed work, an open core governed by a neutral foundation, and a managed layer on top — but avoid making HIVE's commercial fate depend on a single framework or a second scheduler that competes with Kubernetes-native standards.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
