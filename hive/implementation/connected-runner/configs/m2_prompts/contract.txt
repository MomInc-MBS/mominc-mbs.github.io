Reply format. End your reply with exactly one JSON object of the form {"steps": ["<symbol>", ...]} with 1 to 3 strings. Each string must be exactly one symbol from the symbol table, spelled exactly as listed (lowercase, no spaces, no extra characters). The harness uses the last JSON object in your reply whose only key is "steps". It does not change, repair or normalise anything: a reply without such an object, with an unknown symbol, or with a workflow that breaks the grammar or the type rules is refused, and the refusal still uses up that proposal.
