Central question

Separate research paths

Path Question Main experiment
Independent specialists When does independent ownership prevent interference enough to justify extra models? Compare generalists, independent specialists, adapters and hybrids · Use measured interference to test regrouping and routing
Shared backbone and adapters How much specialization can a compatible base support without harmful coupling? Compare generalists, independent specialists, adapters and hybrids · Test bounded memory, correction, retention and removal
Internal experts and expandable memory What can sparse experts inside a model contribute to HIVE's learning? Compare generalists, independent specialists, adapters and hybrids · Test sleep, replay order, expansion and distillation independently · Test bounded memory, correction, retention and removal
Deterministic and nonlanguage experts What is the smallest mechanism that reliably performs a bounded job? Compare generalists, independent specialists, adapters and hybrids · Compare typed messages, precise prose and learned representations
