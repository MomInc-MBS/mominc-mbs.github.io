Scope

Independent implementation of the Google paper, with implementation gaps recorded in DECISIONS.md. Its current README reports mixed outcomes, including no CLINC150 advantage over no-sleep. Useful counterevidence and an audit candidate, not an official release or a local HIVE reproduction.

Use in HIVE

Treat the source's claims and our proposed translation separately. Check the referenced version, task conditions, code/data availability, and resource assumptions before adopting an implementation. A citation does not establish a local reproduction.
