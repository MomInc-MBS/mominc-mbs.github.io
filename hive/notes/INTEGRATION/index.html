HIVE v0.3.0.dev3 integration report

INTEGRATED_PROTOTYPE_DEMONSTRATED — adaptation not yet validated. One executable now connects task intake, governed tool/model execution, independent verification, persisted feedback, candidate comparison and recovery. Both genuine demonstration missions passed. The candidate then lost a critical comparison and was rejected; the next task retained the correct tool policy.

Last verified: 21 November 2026 Las Vegas / 22 November UTC. Independent Terra acceptance is recorded for this bounded development workflow. Level A and Level B remain unaccepted. The public site distributes source and evidence; it is not a hosted model service.

Download runnable source · Runbook · Architecture map · Publication hashes

The latest source includes a separately verified crash-accounting repair. The exact source of the six-call run is archived separately. Historical results retain their original source identity.

One shared execution path

flowchart TD
  T[Scoped task] --> G[Governor and fixed P0]
  G --> E[Shared Executor]
  E --> W[Tool or pinned local model]
  W --> A[Artifacts and events]
  A --> V[Independent verifier]
  V --> F[Attributable development feedback]
  F --> C[Frozen candidate P1]
  C --> X[Separate comparison against controls]
  X --> R[Reject losing candidate]
  R --> N[Next task retains P0]

The governor excludes prohibited, unavailable, unverifiable and over-budget routes before ranking them. Model text has no shell or filesystem authority. The candidate is separate from the governing policy; feedback cannot approve itself. Every executed route has source, task, configuration, model and policy identities attached to immutable evidence. The existing Executor, Store, verifier and Policy remain the shared implementation.

These boundaries do not depend on model size. The real adapter demonstrated here is Ollama. A frontier-model adapter and evidence that HIVE improves a powerful model are future work, not established capabilities.

What this establishes

This is an executed integration with a valid rejected candidate. It does not establish useful adaptive gain, model-weight learning, general intelligence, or superiority over strong AI. The small development comparison has overlapping control routes and repeated classification inputs; it is not an unused holdout or a statistical estimate of general performance. Frozen-label agreement is narrower than universal semantic correctness.

The next hypothesis protects exact-tool capabilities from wasteful candidate exploration. The next task-family gap is actual isolated repository/test work. A future frontier study must compare the same strong model under equal budgets against its strongest simple tool baseline and learning-disabled HIVE, counting independently accepted outcomes and full overhead.
