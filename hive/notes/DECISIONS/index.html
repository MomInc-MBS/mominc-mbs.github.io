Open design decisions

A build needs provisional choices. Research needs the alternatives to remain visible.

Decision Experiment
Independent models or shared components Compare generalists, independent specialists, adapters and hybrids
Where learning should persist Test bounded memory, correction, retention and removal
When HIVE should sleep Compare whole-system and per-specialist sleep during real service
Replay or dreaming Test whether dreaming adds value beyond verified replay
Central or distributed control Scale 100, 1,000 and 10,000 logical experts with measured active workers

Growth, compression, and scale Scale 100, 1,000 and 10,000 logical experts with measured active workers
How far self-improvement may reach Test bounded memory, correction, retention and removal
Knowledge and runtime storage Reproduce prior simulations and separate estimates from measurements
What constitutes verification Test whether dreaming adds value beyond verified replay
How evidence changes a decision Reproduce prior simulations and separate estimates from measurements

Decision rule

  1. Define the workload and resource envelope.
  2. Compare the retained alternatives using the named experiment.
  3. Prefer a branch for those conditions, with uncertainty and tradeoffs visible.
  4. Preserve the other branches and their strongest evidence.
  5. Reopen after a relevant new result, implementation improvement, workload change, or resource change.

No branch is erased solely because the current prototype uses another one.
