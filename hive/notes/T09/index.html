Central question

Which mechanisms improve Ian's video work, live calls, and horror haunt game?

Separate research paths

Path Question Main experiment
Video production and posting Can HIVE reduce repeated work and human repairs in the existing video pipeline? Measure the actual computer and concurrent workload · Compare generalists, independent specialists, adapters and hybrids · Test bounded memory, correction, retention and removal
Live calls and supervisor streaming Can HIVE keep conversation responsive under the user's actual streaming load? Measure the actual computer and concurrent workload · Compare whole-system and per-specialist sleep during real service
Horror haunt game Can modular perception, state, planning, and recovery improve a repeatable encounter? Measure the actual computer and concurrent workload · Compare generalists, independent specialists, adapters and hybrids · Compare typed messages, precise prose and learned representations
