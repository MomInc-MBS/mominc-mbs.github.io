AgentGPT (Reworkd)

Status: historical import; current project condition and numerical claims are not reverified here.
Original catalog category: Multi-agent framework
Original catalog label: Failed — a prior classification, not this plan's experimental verdict.

Prior description

AgentGPT was Reworkd's open-source, browser-based platform that let users name an autonomous AI agent, give it a goal, and watch it decompose the goal into subtasks and execute them in a loop using GPT-3.5/GPT-4.

Research lead carried forward

Copy AgentGPT's frictionless browser demo of goal decomposition, but avoid unbounded general-purpose agent loops — HIVE should ship narrow, evaluable, cost-capped tasks with observability instead of open-ended autonomy.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
