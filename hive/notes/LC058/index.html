Sigma cognitive architecture

Status: historical import; current project condition and numerical claims are not reverified here.
Original catalog category: Cognitive architecture/AGI
Original catalog label: Stalled/Abandoned — a prior classification, not this plan's experimental verdict.

Prior description

Sigma is Paul Rosenbloom's USC Institute for Creative Technologies cognitive architecture that unifies symbolic, probabilistic, and neural cognition — memory, reasoning, learning, perception, and action — in a single factor-graph substrate using summary-product message passing and gradient-descent learning.

Research lead carried forward

Copy Sigma's discipline of a small set of reusable mechanisms and a fast (~50 ms) cognitive cycle, but avoid betting HIVE's core on one elegant unified formalism or a research prototype with a tiny community — keep HIVE modular with fast paths and LLM-native tooling.

This is a historical suggestion to investigate. Adoption requires current primary evidence, a working interface, and a workload comparison.
