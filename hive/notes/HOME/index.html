What this revision changes

  • Make consolidation and dreaming explicit experimental components with their own state, budgets, and acceptance tests.
  • Preserve the earlier replay result and test the mechanisms that it did not cover: Replay ordering and the reopened sleep branch → Sleep consolidation → Test sleep, replay order, expansion and distillation independently.
  • Keep independent specialists, shared adapters, internal experts, deterministic tools, and hybrids as live comparison paths: Independent models or shared components.
  • Use research topics to organize knowledge; use measured transfer and interference to choose parameter-sharing boundaries: How specialists should be grouped.
  • Retain all original research and methods, including negative results and untested proposals.
  • Build around the existing Obsidian, Studio Brain, Graphify source, Ruflo, coding harnesses, and model runtimes after local readiness checks: Existing software and readiness.

Evidence convention

Label Meaning
Primary source reviewed The cited source was inspected; its result is still the authors' result
Prior artifact audited Recovered source/results were inspected; this is not a new training run
Historical import Preserved prior research; current claims have not all been reverified
Proposed experiment Designed here; no result is implied
Metaphor Inspiration whose software translation needs a test
Unresolved An evidence, implementation, or identity gap remains

This package is a research and implementation specification. It contains a linked vault, source history, experiment designs, work packages, schemas, and a link/graph validator. It does not install HIVE on the PC or claim a live integrated benchmark.

Use in Obsidian

  1. Extract the ZIP and open its HIVE_Framework_Research_Vault folder as a vault.
  2. Open this note, then the Canvas or Research Map.
  3. Use Local Graph for a topic and follow links to experiments, history, decisions, and sources.
  4. For integration into the existing vault, follow Vault import and historical preservation; it preserves the current vault and adjusts Canvas file paths when needed.
  5. Give Local coding-agent handoff and AGENTS.md to the local lead coding agent.

The design uses ordinary Markdown links and a standard JSON Canvas. No community plugin is required to read the plan. See Obsidian Graph view and JSON Canvas specification.
