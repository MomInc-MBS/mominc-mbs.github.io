# MYR5 companion — source credits

Three.js 0.180.0 is copied into the local browser bundles. Reused components include the renderer, GLTFLoader, GLTFExporter, OrbitControls, BufferGeometryUtils, AnimationMixer, AnimationAction, AnimationClip, and keyframe tracks.

esbuild 0.27.3 builds the browser modules. Source: https://github.com/evanw/esbuild
MIT license: licenses/esbuild-MIT.txt

The existing MYR5 creature model, anatomy model, style catalog, eye geometry, surface treatments, deformation controls, and coaching personality definitions are reused from Ian's existing MYR5 customizer. These assets are existing project material; no third-party open-source license is asserted for the creature artwork.

The new gesture timings, compatibility rig, app integration, and editor are project-specific code. The gesture clips are authored for this modular creature, using the reused open-source animation system. No humanoid motion-capture pack is included.

The host movement app retains its existing Barehands attribution and AGPL-3.0-or-later LICENSE. This companion does not replace that license.
