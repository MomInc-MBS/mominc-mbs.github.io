# Helping Hand

The editor and companion share this source and the existing creature models. Install with npm ci. To rebuild, copy the adjacent models, previews and fonts folders into public/, then run node scripts/build-embedded.mjs. Serve the resulting dist/embedded files at /handborne/.

Designs retain the handborne-recipe-v4 storage key and all HB1–HB4 recipe imports. The app includes the hand with appearance backup. Bulk libraries remain on the character website; current-hand exports are generated locally.
