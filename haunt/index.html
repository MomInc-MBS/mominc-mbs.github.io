HAUNT

HAUNT is a MOM Inc. AR party horror game. A group of players walks a real house with their phones while a host runs the haunt: monsters roam the rooms, players carry offerings and items, and each haunt ends in a finale the group wins or loses together.

This portal is the engineering inspection layer for HAUNT. It is generated from the project's repository at a known commit and shows what is built, what is tested, what is still open and where a reviewer should look next. It does not publish source code.

What is here

  • Status — verified build state, work in progress, blockers.
  • Architecture — system map and interfaces.
  • Mechanics — the playable haunt loop as it stands.
  • Tests — test outcomes with the revision actually tested.
  • Roadmap — next milestones and open work.
  • Changelog — recent revision-linked changes.
  • Source access — how authorized reviewers reach the code.
  • AI packets — small context packets for AI reviewers; start at ai/INDEX.md.
  • llms.txt and manifest.json — machine-readable index and inventory.

Ground rules

  • Everything here is generated, not hand-maintained status.
  • Missing or old test evidence is shown as not_run or stale, never as passing.
  • Development builds run on a local network. Nothing on this page means a public release.
