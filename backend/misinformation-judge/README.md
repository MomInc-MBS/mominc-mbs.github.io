# Hosted answer judge

Production endpoint: `https://mom-misinformation-judge.mominc-coach.workers.dev/judge`.
This is a separate Worker in the existing MOM Inc. Cloudflare account. It does not expose Ian's computer or connect to agent memories. The deployed model is **Cloudflare Clef Flash**, using the same typed System One decision format as Jev/Laya. It is not a deployment of Laya's weights.

`POST /judge` accepts `{ "answer": "Suez Crisis", "questionId": "history-01" }`. Only server-owned question IDs are evaluated. The response is `{accepted:true, subject:{...}, tier:0..5, provider:"..."}` or `{accepted:false, reason:"..."}`. Failures and uncertainty do not imply a gameplay hit; the client decides when a verified factual classification is graded.

- Reviewed catalog names retain reviewed facts and existing question tiers. A known subject outside a question's curated pool receives a semantic category-fit check instead of an automatic rejection.
- For exact unambiguous catalog aliases, a semantic fit requires FIT to be the selected option, probability at least 0.50 and a margin of at least 0.20 over every alternative. Unknown encyclopedia subjects require identity probability at least 0.76 and fit probability at least 0.72. The separate known-alias gate accepts reasonable verified examples such as D-Day as a government operation while preserving the tested unrelated-answer refusals.
- New names resolve to at most three English Wikipedia title results and summaries. Clef chooses an unambiguous identity and judges category fit from those records. It never supplies the factual statement or source URL.
- New subject statements attribute a description of at most 25 words to the encyclopedia entry. Their `event` classification concerns that documented record, and does not endorse associated allegations. Their unmeasured answer rarity defaults to tier 0. Known subjects outside a pool use a conservative editorial familiarity tier.
- Requests have a 4 KB streaming cap, 120-character name cap, fixed source host, per-IP limit of 12/minute, and 13-second verification deadline. A strongly consistent Durable Object limits uncached checks globally to 60/minute and 4,000/day. It stores only four aggregate counters. New-subject checks count against that budget even when no clear record is found. No raw answers or IPs are written by application code.
- Hashed decision-cache keys include the question prompt and answer pool. Successful judgments cache for one day; semantic refusals for ten minutes. Cloudflare's cache is per location; the global spending counter is not. CORS accepts mominc.online, www.mominc.online, and the local development origins on port 5190. CORS is not authentication; spending and request limits remain enforced server-side.
- Cloudflare platform observability is sampled. Application code emits no request-body logs. Public encyclopedia submissions and inference are processed by their respective providers. There is no chat, agent, filesystem, or arbitrary-URL tool exposed to the model.

Run `npm ci`, `npm test`, `npm run check`, then `npm run deploy`. Wrangler is pinned to 4.92.0. Authentication uses the existing local Wrangler login; there are no committed keys or browser-side inference secrets. The Worker imports the current `play/misinformation/catalog.js`; **redeploy it after rebuilding that catalog**. Source and model failures return retryable responses; the UI must preserve the paused answer and allow retry.

The unit suite covers off-pool handling, abstention, fixed factual output, streamed caps, origin checks, source allowlisting and redirect refusal, malformed models, caching and aggregate quota resets. Model confidence thresholds are operational gates tested on examples, not a claim of calibrated factual accuracy.

Verified on the actual public endpoint on October 15, 2026: Cuban Missile Crisis and its `Cuban Missle Crisis` variant, Suez Crisis and Hurricane Katrina were accepted for appropriate history/disaster prompts. Suez Crisis and Watergate were rejected for `space-01`. Novel records for the Empress of Ireland sinking and Great Fire of Rome were accepted through actual encyclopedia retrieval and hosted Clef inference. The final version also accepted D-Day for `programs-05` despite its absence from that question's curated pool, and resolved the Bielefeld conspiracy as a documented encyclopedia subject; the latter's attributed reference statement does not endorse that story. Banana and an instruction-injection attempt were rejected for `history-01`. These are targeted examples, not a general accuracy benchmark. Final deployed version: `45ac39ef-ea60-4ead-8103-24b45ebaf0d6`; health reports version `2026-10-15-v2`, 204 subjects and 184 prompts. All 19 unit tests pass. Workers Fetch requires `redirect: 'manual'`; Node's accepted `redirect: 'error'` is not supported there.
